# game2048 🎲

终端里的 2048 小游戏：4×4 棋盘，移动方块、合并相同数字，拼出 2048！

纯 Python 标准库，零依赖，单文件。

## 玩法

```bash
python -m game2048
```

操作（回车确认）：

| 按键 | 方向 |
|------|------|
| W / K | 上 |
| S / J | 下 |
| A / H | 左 |
| D / L | 右 |
| Q | 退出 |

为什么是字母键而不是方向键？方向键需要把终端切到 raw 模式逐字节读取，纯 `input()` 行读取做不到；WASD + HJKL 两套别名在任何终端、SSH 里都好使。

规则：

- 每次有效移动后，在随机空格生成一个新方块（90% 是 2，10% 是 4）
- 相同数字相撞合并，得分累加合并出的数字
- **每个方块每步只合并一次**：`[2,2,2,2]` 左移变成 `[4,4,0,0]`，不会直接变成 `[8,0,0,0]`
- 首次拼出 2048 即获胜（可继续挑战更高分）；棋盘填满且无路可走则游戏结束

## 自动模式（验证 / 跑统计）

```bash
python -m game2048 --auto 200 --seed 1   # 随机走 200 步，固定种子可复现
python -m game2048 --auto 1000 --seed 42
```

输出步数、得分、最大方块、是否获胜、终局棋盘。

## 设计取舍

- 四个方向的移动逻辑全部归约到"向左移动一行"：右移=反转行， 上移=转置， 下移=转置+反转行。一份合并代码，四处复用，bug 面最小。
- 合并用"压缩→两两合并（跳过已合并）→补零"三段式，天然保证单次合并。
- 游戏结束判定：有空格就能走；无空格时检查任意横/竖相邻两格是否相等。

## 已知局限

- **没有悔棋（undo）**：走错一步只能重开。交互模式是行读取，每步都要按回车，节奏比网页版慢一拍。
- 不支持方向键（见上）。
- 棋盘固定 4×4，没有 5×5 / 6×6 模式。
- 颜色用 ANSI 转义序列；在不支持 ANSI 的终端里加 `NO_COLOR` 也不会自动降级——不过棋盘本身是纯文本对齐，不影响玩。
